# Project Brief: Pro Athlete Fitness Gym

## 🎯 Overview
A full-stack web application designed for managing a personal training business. It provides a public-facing website for clients and a secure admin panel for the trainer to manage operations.

## 🏗️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Shadcn/ui (Deployed on Vercel)
- **Backend**: Node.js, Express, TypeScript, MongoDB (Mongoose), JWT (Deployed on Render)
- **Services**: SMS via Twilio, File uploads via Multer, Scheduling via node-cron

## 🔑 Key Features
### Public Facing
- Hero section with dynamic images.
- About Trainer bio and credentials.
- Client Transformation gallery.
- Dynamic Pricing Plans.
- Lead capture form with WhatsApp integration.

### Admin Panel
- **Dashboard**: High-level stats on clients, leads, and revenue.
- **Client Management**: Full CRUD, membership expiry tracking.
- **Lead Tracking**: Sales pipeline management.
- **Payments**: Transaction history and recording.
- **SMS Automation**: Daily reminders for expiring memberships.
- **CMS**: Update website content (images, text, pricing) without code.
